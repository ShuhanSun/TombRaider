# 寻龙诀 · Tomb Raider

一款无需安装、无外部依赖的俯视角古墓生存游戏。扮演摸金校尉，探索十层随机古墓，寻找镇墓冥器，并从盗洞逃出生天。

[开始游戏 / Play](https://shuhansun.github.io/TombRaider/)

## 操作

| 动作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 右下方摇杆 |
| 疾行 | 按住左 / 右 Shift | 移动时按住「疾行」 |
| 开棺 | 靠近石棺约 0.6 秒，随后等待棺盖开启 | 同左 |
| 暂停 / 继续 | Esc 或右上角暂停按钮 | 右上角暂停按钮 |
| 静音 | M 或声音按钮 | 声音按钮 |

切换窗口或锁屏会自动暂停，回来后手动继续。语言可在开始画面切换。

## 探索规则

每层有且只有一件镇墓冥器。开棺可能遇到空棺或起尸；取得冥器后，出口房间涨水，盗洞开启。第十层从盗洞离开即获胜。角色有五点生命，水域会减慢移动速度。

小地图逐步记录视野附近的区域，并标出已发现的未开石棺。拾取风水罗盘后，方向箭头和金色地图标记先指向冥器，取得后改为指向盗洞。罗盘显示目标方向，不提供绕墙路线。

千年油灯扩大视野，最高 750；风水罗盘与油灯跨层保留。糯米酒恢复一点生命。黑驴蹄子驱避僵尸 15 秒，但不能抵挡机关和已有弹丸；金缕玉衣免疫伤害 15 秒。临时增益不跨层保留。出生房间不生成敌人和机关，到达新楼层有两秒保护。

## 本地运行

```sh
python3 -m http.server 8000
```

在浏览器打开 `http://localhost:8000`。无需构建或安装运行依赖，部署时同时保留 `index.html`、`styles.css` 和 `game.js`。

## 验证

需要 Node.js 22 或更高版本，无需安装 npm 包：

```sh
node --check game.js
node --test tests/game.test.cjs
```

测试覆盖启动与中英文切换、300 张随机地图的连通性与安全出生点、异常随机序列的地图回退、30/60/144 Hz 时钟、暂停与重开、伤害规则、特效生命周期、双指输入和十层通关。逻辑测试使用 DOM / Canvas 替身，不能代替真实浏览器和手机的视觉、触控及音频验收。

## 项目结构

- `index.html`：界面与入口。
- `styles.css`：古墓主题、桌面与移动布局。
- `game.js`：随机地图、实体、输入、音效、固定时间步模拟和绘制。
- `tests/game.test.cjs`：无第三方依赖的回归测试。

模拟以 60 Hz 推进，渲染跟随显示器刷新率；每帧最多补算 0.1 秒，避免长时间卡顿后角色瞬移。仅对屏幕附近实体排序和绘制，小地图与状态栏以 10 Hz 刷新。画布适配高像素密度屏幕，像素倍率最高为 2。
